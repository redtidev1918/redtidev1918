# hi

主要在做内容平台相关的自动化小工具，Pixiv、Telegram/Telegraph、DeviantArt 这几块，
偶尔写点 Flutter 桌面应用和小游戏。常用 TypeScript / Python / Dart。

## Pixiv

- [PixivFlow](https://github.com/redtidev1918/PixivFlow) — Pixiv 自动下载
- [pixivflow-webui](https://github.com/redtidev1918/pixivflow-webui) — PixivFlow 的 React 前端
- [pixivflow-telepost-deploy](https://github.com/redtidev1918/pixivflow-telepost-deploy) — 低内存部署套件
- [pixiv-token-getter](https://github.com/redtidev1918/pixiv-token-getter) — 取 Pixiv token 的库和命令行

## Telegram / Telegraph

- [TelePost](https://github.com/redtidev1918/TelePost) — Telegram 频道投稿机器人，带搜索、热度统计、标签
- [telepress](https://github.com/redtidev1918/telepress) — 往 Telegraph 发文章和图的 Python 库，`pip install telepress`
- [graf](https://github.com/redtidev1918/graf) — 自托管的极简 Markdown 发布平台，兼容 Telegraph API

## DeviantArt

- [daviewer](https://github.com/redtidev1918/daviewer) — 开源 DeviantArt 客户端，Flutter 写的，Android / macOS / Windows
- [deviantart-downloader](https://github.com/redtidev1918/deviantart-downloader) — DeviantArt 批量下载
- [dakit](https://github.com/redtidev1918/dakit) — DeviantArt 的 Dart / Flutter SDK

## 其他

- [NekoTime](https://github.com/redtidev1918/NekoTime) — 桌面上的悬浮小猫时钟
- [LuckyReels](https://github.com/redtidev1918/LuckyReels) — 类《幸运房东》的 roguelike 老虎机，Phaser + TS
- [GameLib](https://github.com/redtidev1918/GameLib) — 跟引擎无关的小游戏系统库
- [paranote](https://github.com/redtidev1918/paranote) — 给任意网页加段落评论，顺带做阅读器
