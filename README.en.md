## Naming convention

- Products / apps / platforms: PascalCase (for example, `PixivFlow`, `TelePost`, `DAViewer`)
- CLIs / libraries / infrastructure: kebab-case (for example, `deviantart-downloader`, `pixivflow-telepost-deploy`)

## Docs & downloads

- Every project ships a unified bilingual docs site generated by
  [docsite](https://github.com/redtidev1918/docsite): `https://redtidev1918.github.io/<repo>/`
- The "Download" page on each site lists per-platform packages and checksums,
  always pointing at the latest release; everything else lives in the repos' Releases.
